# Handout: Month 1 – Python for Machine Learning

## Overview

This month is designed to take you from zero to comfortable with Python, specifically focusing on the skills you need for machine learning. By the end of Week 4, you will be able to write clean Python code, handle real-world data files, and perform basic numerical analysis using Pandas.

The curriculum follows a project-based approach, with weekly assignments to reinforce concepts. The goal is not just to watch videos but to code alongside them.

---

## Weekly Breakdown

### Week 1: Python Basics and Core Data Structures

**Focus Areas:**
- Setting up your Python environment (VS Code, Python installation)
- Working with strings, integers, and floats
- Understanding lists, tuples, and sets
- Indexing, slicing, and basic collection operations

**Why this matters:**
Data in machine learning is represented as collections — lists of features, tuples of coordinates, sets of unique categories. A solid grasp of these data structures is essential.

**Tip:** Focus on understanding list indexing and slicing. These are used constantly when working with datasets.

---

### Week 2: Dictionaries, Conditionals, Loops and Functions

**Focus Areas:**
- Using dictionaries for key-value data
- Writing if, else, and elif statements
- Using for and while loops
- Defining and calling functions with parameters and return values

**Why this matters:**
Dictionaries are the backbone of data processing pipelines (think JSON or column mappings). Functions help you write reusable code and are the building blocks of any ML script.

**Tip:** Practice writing small functions that take inputs and return outputs. This builds muscle memory for coding interviews and real-world projects.

---

### Week 3: Modules, File I/O and Error Handling

**Focus Areas:**
- Importing and using Python modules
- Interacting with the operating system (os module)
- Reading from and writing to files (file objects)
- Parsing CSV files for data processing
- Handling errors gracefully (try / except blocks)

**Why this matters:**
In machine learning, 80% of the work is data cleaning. This week prepares you to read dirty CSV files, handle corrupt rows, and save clean data — a critical real-world skill.

**Tip:** Pay extra attention to the try / except section. It is often skipped by beginners but is the difference between a script that crashes and one that runs reliably.

---

### Week 4: Essential Data Science Libraries (NumPy and Pandas)

**Focus Areas:**
- Introduction to NumPy arrays and vectorized operations
- Introduction to Pandas DataFrames for tabular data
- Reading CSV and Excel files
- Filtering, sorting, grouping, and basic data manipulation

**Why this matters:**
NumPy and Pandas are the foundation of the Python data science stack. You will use them in every subsequent ML project. This week transitions you from generic Python to data-focused Python.

**Tip:** The video for this week is long. Watch it in 20-minute chunks and pause to try every example in a Jupyter notebook. Hands-on practice is essential here.

---

 **Pro Tip:** As you progress through the weeks, save small code snippets (e.g., CSV reading, exception handling, list comprehensions) in a dedicated Python file or Google Colab notebook. Reusing your own work is faster than rewriting everything from scratch later.
